# Desktop Cultivator 桌面修仙徒弟

这是一个 Steam 桌面挂机修仙宠物 MVP 原型。

## 核心概念

玩家开着电脑工作时，一个小修士会挂在桌面角落自动修炼。
他会打坐、获得修为、捡灵石、吃丹药、突破境界，也会突破失败被心魔反噬。

## 当前版本功能

- 透明桌面窗口
- Always-on-top 置顶
- 可拖动窗口
- 自动修炼
- 境界系统
- 灵石系统
- 聚气丹按钮
- 加速打坐按钮
- 突破成功 / 失败
- 离线收益
- 本地存档

## 如何打开

1. 下载 Godot 4.x
2. 打开 Godot
3. Import 这个资料夹
4. Run Project

A tiny cultivation disciple lives on your desktop, meditating, breaking through realms, collecting spirit stones, and occasionally failing tribulations while you work.

## 中文简介

你的桌面住着一个修仙徒弟。你工作、剪片、写稿的时候，他会自己打坐、吐纳、收集灵石、尝试突破境界。偶尔他会顿悟，也可能被心魔反噬。你不需要一直操作，只需要偶尔看一眼：他是不是又偷偷变强了？

## 商业定位

- 喜欢挂机游戏的人
- 喜欢修仙题材的人

## 注意

这是 MVP 原型，不是完整商业版。它的价值是验证核心体验：

> 一个修仙角色在桌面上自动成长，玩家只需要偶尔陪伴和干预。
